# ناشر صلة

ينشر منشورات صلة على فيسبوك وإنستغرام عبر واجهة Meta الرسمية المجانية. يشغّله GitHub Actions كل 15 دقيقة.

## كيف يعمل
- `queue.json` فيه كل منشور: الشبكة، والنوع (post أو story)، والصور، والنص، والموعد، و`approved`.
- لا يُنشر أي عنصر إلا إذا كان `approved: true`. يضبطه Claude بعد موافقة المالك على المنشور.
- منشورات فيسبوك تُجدول على خوادم Meta فور الموافقة. إنستغرام والستوريات تُنشر في موعدها، وقد تتأخر حتى 15 دقيقة أو أكثر قليلاً.
- منشور فات موعده بأكثر من 3 ساعات لا يُنشر متأخراً. يُعلَّم `failed` مع السبب.
- الصور في `media/` بصيغة JPEG. يجب أن يكون المستودع عاماً حتى تصل إليها Meta.

## الإعداد (مرة واحدة)
- GitHub Secret باسم `META_TOKEN`: مفتاح مستخدم النظام من حافظة Miss Levora.
- GitHub Variable باسم `PAGE_ID`: `106327508973515`.

## أوامر
```
python publisher.py check    فحص الطابور بلا اتصال
python publisher.py whoami   فحص المفتاح
python publisher.py run      النشر (يشغّله GitHub)
```
