# ناشر صلة

ينشر منشورات صلة على فيسبوك وإنستغرام عبر واجهة Meta الرسمية المجانية، من GitHub Actions، بلا حاجة لحاسوب المالك.

## كيف يعمل
- `queue.json` فيه كل منشور: الشبكة، والنوع (post أو story)، والصور، والنص، والموعد، و`approved`.
- لا يُنشر أي عنصر إلا إذا كان `approved: true`.
- **مناوبات متصلة:** كل تشغيل يبقى قرابة 5 ساعات ونصف ويفحص الطابور كل دقيقتين، ثم يبدأ التشغيل التالي بنفسه. الجدولة كل ساعة احتياط إن انقطعت السلسلة. فالتأخير عن الموعد دقيقتان تقريباً.
- منشور فيسبوك **بصورة واحدة** يُجدول على خوادم Meta مسبقاً.
- منشور فيسبوك **بعدة صور (كاروسيل)** يُنشر في موعده: تُرفع الصور غير منشورة ثم تُرفق بمنشور واحد. Meta ترفض لهذه الصفحة الصور المؤقتة اللازمة للجدولة المسبقة، فلا نجدوله. إن رفضت Meta الكاروسيل، يُنشر بالصورة الأولى ويُفتح تنبيه. وكاروسيل جدوله الكود القديم (قبل 5 تشرين الأول 2026) بصورة واحدة وموعده لم يحن: تُحذف جدولته لدى Meta ويعود إلى الانتظار ليُنشر كاملاً في موعده (`unschedule`)، ويُحفظ المعرّف القديم في `superseded`.
- إنستغرام والستوريات تُنشر في موعدها.
- **الريلز** (`kind: "reel"` و`video: "media/<folder>/<name>.mp4"`): يُنشر في موعده على فيسبوك (`video_reels`) وإنستغرام (`REELS` مع الظهور في الخلاصة). الملف يُرفع إلى Meta مباشرة لا برابط، لأن GitHub يقدّم mp4 بنوع غير مناسب. `check` يفحص أن الفيديو 9:16 بعرض 540 على الأقل ومدته من 3 إلى 90 ثانية وحجمه أقل من 95MB. وقبل أول ريلز حقيقي: سير العمل `videotest` (يبدأ وحده عند دفع تغيير إلى `media/test/`، أو من Actions) يرفع `media/test/reel-test.mp4` إلى الشبكتين بلا نشر (مسودة فيسبوك تُحذف، وحاوية إنستغرام لا تُنشر)، والفشل يفتح Issue فيه الخطأ.
- **سحب الموافقة:** عنصر يصير `approved: false` لا يُنشر. وإن كان منشور فيسبوك مجدولاً لدى Meta وموعده بعد أكثر من 20 دقيقة، تُحذف جدولته ويعود إلى `pending`، ولا يُنشر حتى يُوافق عليه من جديد.
- عنصر يفشل يُعاد بعد 15 دقيقة، حتى 3 محاولات. منشور فات موعده بأكثر من 12 ساعة لا يُنشر متأخراً.
- **التنبيه:** أي فشل نهائي، أو كاروسيل نُشر بصورة واحدة، يفتح Issue في المستودع، فيصل بريد من GitHub.
- الصور في `media/` بصيغة JPEG. يجب أن يكون المستودع عاماً حتى تصل إليها Meta.

## الإعداد (مرة واحدة)
- GitHub Secret باسم `META_TOKEN`: مفتاح مستخدم النظام من حافظة Miss Levora.
- GitHub Variable باسم `PAGE_ID`: `106327508973515`.

## أوامر
```
python publisher.py check    فحص الطابور بلا اتصال
python publisher.py whoami   فحص المفتاح
python publisher.py run      النشر مرة واحدة
python publisher.py videotest  اختبار رفع ريلز بلا نشر
python publisher.py loop     مناوبة متصلة (يشغّلها GitHub)
```
